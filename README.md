# ShopApp

E-commerce fullstack construido con Node.js, Express y PostgreSQL.

## Demo
[shopapp-xxxx.onrender.com](https://shopapp-xxxx.onrender.com)

## Stack
- **Frontend**: HTML, CSS, JavaScript vanilla
- **Backend**: Node.js + Express
- **Base de datos**: PostgreSQL (prod) / SQLite (dev)
- **Auth**: JWT + bcrypt

## Funcionalidades
- Registro y login con JWT
- Catálogo de productos con filtros
- Carrito con control de cantidades
- Órdenes con validación de stock
- Deploy automático en Render

## Correr localmente
\`\`\`bash
cd backend
npm install
node db/seed.js
node server.js
\`\`\`
